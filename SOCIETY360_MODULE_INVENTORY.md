## Evidence and counting rules

- Static page inventory was derived from `wwwroot/modules/society-admin/index.html` and `admin.js`.
- The application navigation is database-driven: `admin.js` loads `/api/menu`, nests records by `parent_module_code`, and renders leaf buttons. Therefore source aliases alone are not treated as the definitive live menu count.
- The prepared read-only Chrome inventory test (`scripts/navigation_inventory_chrome_e2e.py`) requires a Chrome DevTools endpoint at `127.0.0.1:9335`; that endpoint refused connections during this pass. The currently open visible Chrome session was not restarted or logged out. The exact live menu/submenu count and full click-by-click result remain **unverified**, not guessed.
- Static route sections found in `index.html`: `home`, `customers`, `flats`, `bills`, `collection`, `complaints`, `visitors`, `parking`, `security`, `configuration`, `billing-configuration`, `billing-process`, `module-workspace`, `accounts` (**14 source-defined view sections**). This is a source count, not the number of live menu entries.
- Configured language options observed in the current Collection Management workflow and source: English (`en`), Hindi (`hi`), Marathi (`mr`), Gujarati (`gu`), Kannada (`kn`), Tamil (`ta`). This is the six-language set to preserve.
